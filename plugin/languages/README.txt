LCode languages plugin

This plugin enables automatic, extension-based syntax highlighting for Java,
Go, Rust, C#, Kotlin, Swift, Dart, Scala, PHP, CSS, HTML/XML, SQL, Ruby, Perl,
R, YAML, TOML, Dockerfiles, Makefiles, INI/config files, and HCL/Terraform.

The built-in LUC plugin continues to handle LUC, C/C++, Python, JavaScript and
TypeScript, Lua, PowerShell, shell scripts, JSON, and Markdown. The detected
language comes from the opened file name; no manual language selection is
needed.

Highlighting is lexical rather than a full parser or language server. It colors
common keywords, strings, numbers, comments, and function calls. Toggle this
plugin or its Language highlighting setting from LCode's plugin controls.
